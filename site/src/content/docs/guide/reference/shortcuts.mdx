On Windows and Linux, use <kbd>Ctrl</kbd> where this page shows <kbd>⌘</kbd>.

## Anywhere in Chrome

These work whichever window has focus, including the page you're sharing.

| Shortcut | Action |
|---|---|
| <kbd>Alt</kbd> <kbd>Shift</kbd> <kbd>P</kbd> | Open pagecue for the current tab, or bring the prompter forward |
| <kbd>Alt</kbd> <kbd>Shift</kbd> <kbd>↓</kbd> | Next cue |
| <kbd>Alt</kbd> <kbd>Shift</kbd> <kbd>↑</kbd> | Previous cue |

To change them, open `chrome://extensions/shortcuts`.

## In the prompter

When the prompter window has focus.

| Shortcut | Action |
|---|---|
| <kbd>↓</kbd> <kbd>→</kbd> <kbd>Space</kbd> <kbd>PageDown</kbd> <kbd>j</kbd> | Next cue |
| <kbd>↑</kbd> <kbd>←</kbd> <kbd>PageUp</kbd> <kbd>k</kbd> | Previous cue |
| <kbd>P</kbd> | Pause or resume following |
| <kbd>N</kbd> | Add a cue at the reading line |
| <kbd>Enter</kbd> | Edit the current cue |
| <kbd>L</kbd> | Show or hide section lines on the page |
| <kbd>S</kbd> | Open Sites |
| <kbd>?</kbd> | Open the ··· menu at the shortcut list |
| <kbd>⌘</kbd> <kbd>+</kbd> | Larger text |
| <kbd>⌘</kbd> <kbd>−</kbd> | Smaller text |
| <kbd>Esc</kbd> | Close the menu or Sites |

Presentation clickers send <kbd>PageDown</kbd> and <kbd>PageUp</kbd>, so they move through cues while the prompter has focus.

## While editing a cue

| Shortcut | Action |
|---|---|
| <kbd>Enter</kbd> in the headline | Go to the points |
| <kbd>⌘</kbd> <kbd>Enter</kbd> | Save |
| <kbd>Esc</kbd> | Cancel and put the words back |

## In Sites

| Shortcut | Action |
|---|---|
| <kbd>Enter</kbd> while renaming | Save the name |
| <kbd>Esc</kbd> | Cancel renaming, or close Sites |
